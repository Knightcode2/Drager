What it is

Most file jobs are small: shrink a photo, turn a Word file into a PDF, black out a number, lock a PDF with a password. DragShift puts all of them in one place that appears exactly when you are already holding the file.

Originals are never changed

Every result is saved as a new file next to the original. If you don't like it, press Undo and the new file goes to the Recycle Bin.

Works offline

Files are processed on your PC. Nothing is uploaded, so private documents stay private.

Lives in the tray

It runs quietly in the system tray, can start with Windows, and uses a menu you open only when you need it.

How it works

Four steps, all with the mouse and one key.

  1. Start dragging

    Pick up an image, PDF, Word or text file in File Explorer or on the desktop.

  2. Press Shift

    The menu opens under your cursor. Tap Shift again to switch between Convert and Tools.

  3. Drop on a slice

    Choose the action by dropping the file on it. Tools that need options open a small window.

  4. Check the result

    The new file appears beside the original. A notification shows what changed, with Open, Show in folder and Undo.

Prefer not to drag? Right-click a file and choose DragShift…, use Send to → DragShift, or double-click the tray icon to pick a file.

Download the repository, unzip it and double-click Install-DragShift.bat. It installs Python and Inno Setup if missing, builds the app and opens the installer. Or run it directly:

Questions

Does it upload my files anywhere?

No. Conversion and editing happen on your computer.

Will it overwrite my original file?

No. Results are saved as new files, and Undo moves the new file to the Recycle Bin.

Why does Windows warn me when I run it?

The app is not code-signed yet, so SmartScreen does not recognise it. Use More info → Run anyway. Signing through the SignPath Foundation is planned for Windows builds.

Do I need Microsoft Word to convert Word files?

No. If Word is installed DragShift uses it for the best fidelity; otherwise it uses a built-in renderer.

Where is my log file if something goes wrong?

At %LOCALAPPDATA%\DragShift\log.txt. You can attach it when you open an issue.

How do I remove it?

Use Settings → Apps → DragShift → Uninstall. The portable exe can simply be deleted.
